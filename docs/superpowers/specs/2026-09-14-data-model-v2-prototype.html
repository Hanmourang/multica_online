Ⅰ能力总览本期数据模型模块 v2 的三项能力与数据流

画面 1 · 数据模型模块 v2 能力总览 —— 三视角全面版本化 + 资产双向绑定

在 v1（2026-09-05，画面 11 总线矩阵）基础上做三项增强：① 矩阵可编辑 —— 行（模块×页面）与列（数据域）都支持增删、改名、排序、显隐，格子点击直接弹出资产挂载弹窗，手动挂载与图谱自动识别双源合并；② 数据 / 迭代视角版本化 —— 每次图谱扫描生成一个快照版本，任意两版本可对比，资产表粒度追踪 新增 / 修改 / 删除（下钻到列级 diff）；③ 资产 ↔ 功能模块绑定 —— 每张表有 360° 视图：被哪些模块、哪些产品页面使用，前端组件 → API → 服务 → 表的前后端调用链逐跳可见。

Multica — 数据模型模块 v2 · 能力地图
能力 ①

矩阵可编辑 + 资产挂载 1

矩阵不再是只读投影，行列元素全部可调整，格子是资产挂载的入口。

  • 行三级可编辑：产品模块 / 子功能（页面）/ 业务过程（主键组合）均可增删、改名、排序、隐藏
  • 列调整：数据域增删、改名、排序、合并拆分
  • 点格子 → 资产挂载弹窗：挂载 / 解除 / 忽略表资产
  • 手动挂载 > 图谱自动识别；忽略不等于删除图谱边
能力 ②

版本化数据 / 迭代视角 1

每次 scan 落一个快照版本，迭代情况 = 两版本间的资产差集。

  • 版本选择器：当前版本 vs 任意基线版本对比
  • 资产表追踪：新增 / 修改 / 删除 / 不变 四态
  • 修改下钻到列级 diff（+列 / −列 / 类型变更）与 migration 号
  • 变更角标回投矩阵格子：▲新增 ◆修改 ✕删除
能力 ③

资产 360° 绑定 1

从「表」出发反查「谁在用」，前后端调用链完整可见。

  • 表 → 绑定的功能模块 × 产品页面 清单（R/W 拆分）
  • 调用链：React 页面 → Hono API → service → SQL → 表
  • 边类型：FETCHES / QUERIES / WRITES / ACCESSES
  • 孤儿链路告警：无前端入口、无后端写者、deprecated 仍被调

画面 2 · 产品视角矩阵 — 三级行（模块 / 子功能 / 业务过程）× 列（数据域）全部可编辑

行的语义升级为三级产品动线结构：产品模块 → 子功能（页面）→ 业务过程（主键组合）。一个功能页面下可挂多个业务过程，业务过程回答「用户在这个页面做什么」（如 需求详情页 = 详情读取 / 评论互动 / 阶段流转），格子粒度随之细化到业务过程 × 数据域，页面单元格显示小计。模块、子功能、业务过程三级行与数据域列全部可动态编辑：拖拽 ⠿ 排序、✎ 改别名（不改图谱事实）、👁 隐藏、＋ 新增（手动增补带橙色刻度），全部存入 bus_matrix_layout 增量层（按项目持久化），点「恢复自动布局」一键回到图谱推导结果。浏览态点格子直接弹出资产挂载弹窗（画面 3）；格子左上角 ▲◆✕ 变更角标回投迭代对比结果。
