Multica 客户端 · 三大模块功能动线原型

本原型基于 2026-09-04 需求日历 + 角色化流水线 与 2026-09-05 项目档案库 两份原型，按客户端「工作区 → 任务 / 日历 / 项目」三个功能模块拆解完整功能动线。 每个画面标注模块基础功能与交互详情；画面中的 → 跳转 按钮为可点击锚点，真实演示页面间流转。 三条动线共享同一套数据事实：需求（issue 顶层 + 日历字段）→ 阶段流水线（stage 1-4）→ 子任务（parent_issue_id）→ 交付物 → 项目档案。

③ 本原型相对前两份深稿的关键变化

1任务详情收敛现状是「需求下钻三 TAB（动态/进度追踪/交付概览）+ 原生动态 + 右栏执行日志」三层叠加。本原型按最新决策：移除需求下钻三 TAB 区块，只保留原生「动态」时间线；「执行日志」从右栏提升为主栏 TAB，与「动态」并列；属性栏新增「需求」信息卡。
2日历不再割裂新建需求后，原型确认 / 拆解 / 调度 / 验收四块内容收进同一个「需求工作台」容器：顶部阶段条驱动面板切换，右栏常驻需求信息；日历色块、待确认角标、工作台三处入口同源。
3项目八 TAB 定序项目详情 TAB 固定为：项目档案 → 功能模块 → 数据模型 → 需求管理 → 任务追踪 → 验收详情 → 交付物 → 申报。功能模块与数据模型在图谱自动投影之外补齐人工管理能力；新增「需求管理」概览页与「验收详情」回炉动线。

A1工作区 → 任务 · 任务主页（看板，布局不变）
