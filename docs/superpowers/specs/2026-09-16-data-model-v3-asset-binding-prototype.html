画面 1 · 数据模型模块 v3 增量 —— 物理表 × 逻辑表双轨资产模型

v2 已交付「点格子直接弹挂载 + 三视角版本化」。v3 在此之上回答一个问题：挂到格子里的「数据资产」到底是什么形态？拆为两轨——物理表：真实落库的数据表，含业务库真实表与数仓 ODS（贴源）/ CDM（公共维度）分层表；逻辑表：不落数据的虚拟视图，以业务过程（= 矩阵行的维度主键组合）为轴，把多张物理表的指标按口径挂载组装成一张逻辑宽表。绑定弹窗与数据模型子 TAB 同时支持双轨：弹窗内可添加/绑定两类资产；数据视角清单拆「物理表 / 逻辑表」两个子 TAB，逻辑表行可展开指标构成血缘。

Multica — 数据模型 v3 · 资产模型语义
能力 ①

绑定弹窗：添加 + 绑定双轨资产 f2/f3

点击矩阵格子弹出的绑定窗口中，每行资产带类型徽章（物理表 / 逻辑表）与分层徽章（业务库 / ODS / CDM）；「绑定新资产」区按类型切换：物理表态提供分层筛选 + 搜索候选；逻辑表态可选已有逻辑表，或就地展开组装器新建。

能力 ②

逻辑表组装器 f3

以格子的业务过程为维度主键组合（如 issue·detail → workspace_id + issue_id），逐行挂载「来源物理表 · 列 → 聚合口径 → JOIN 键」为指标，实时预览生成的 CREATE VIEW。逻辑表不落数据，定义入增量层，查询时下推到物理表。

能力 ③

数据模型子 TAB：物理表 / 逻辑表 f4/f5

数据视角清单拆三个子 TAB：全部 / 物理表 / 逻辑表。物理表 TAB 增加「分层」列与筛选；逻辑表 TAB 展示业务过程（维度主键组合）、挂载指标数、来源物理表数，行内可展开指标构成血缘。

视图预览 4
-- 逻辑表不落数据，定义即视图；查询时下推来源物理表 CREATE VIEW lg_issue_detail_view AS SELECT i.workspace_id, i.id AS issue_id, i.priority_score, AVG(r.progress_pct) AS avg_progress_pct, COUNT(a.id) AS deliverable_cnt, MAX(o.synced_at) AS last_synced_at FROM issue i LEFT JOIN agent_run r ON r.issue_id = i.id LEFT JOIN project_artifact a ON a.issue_id = i.id LEFT JOIN ods_issue_sync_raw o ON o.issue_id = i.id GROUP BY i.workspace_id, i.id;
视图定义入 logical_table_def（维度主键 + 指标血缘） · 绑定入 asset_mount（asset_kind = logical） · 逻辑表不落数据 取消 保存并绑定到本格子
1 先复用后新建：逻辑表候选按「同业务过程优先 + 已被引用次数」排序，避免同一过程被重复定义多张近似视图 2 组装器三要素：逻辑表名（项目内唯一）+ 维度主键组合（继承业务过程，可扩列）+ 指标挂载行（来源表 · 列 → 口径 → JOIN 键） 3 维度主键组合 = 产品动线的数据锚点：业务过程定义了「谁在读这张逻辑表」，维度主键定义了「以什么粒度读」；二者共同决定视图 GROUP BY 4 SQL 实时预览：组装过程所见即所得；口径非法（如对文本列 SUM）在保存前即时拦截
